# 通用语言词汇表

本文件记录项目的领域术语，消除歧义。当术语有多个含义、命名不清或需要沉淀时，在此补充词条。
词条格式机器可解析（`## 术语` + `- **含义**：` 一行），由 `zcode ticket gloss` 命令管理：
`zcode ticket gloss` 列出、`zcode ticket gloss <术语>` 查询、`zcode ticket gloss add <术语> <定义>` 记录。

### 词条格式

```markdown
## 术语名
- **含义**：一句话定义
- **别名/冲突**：其他叫法或需要澄清的歧义
```

## EMC
- **含义**：电磁兼容：设备在电磁环境中正常工作且不对其他设备造成不可接受干扰的能力

## EMI
- **含义**：电磁干扰：外部电磁能量耦合导致设备性能下降的现象

## ESD
- **含义**：静电放电：静电能量快速释放形成的瞬态电磁干扰

## 测试委托单
- **含义**：客户委托 EMC 测试的业务单据，LIMS 流程入口

## 样品
- **含义**：客户送测的被测产品，测试工单与测试执行的载体

## 测试报告
- **含义**：记录 EMC 测试项目、方法与结果的交付文档

## 原始记录
- **含义**：测试执行过程产生的第一手记录，含结构化结果与附件；修订不改原文、留修订痕

## 签发
- **含义**：管理角色确认报告有效的批准动作，报告对外发放的前提；二级流程=工程师自检→管理审核签发

## 排程日历
- **含义**：测试任务按 日期×工程师×设备 安排的日历视图，支持拖拽排程与冲突高亮

## 表单层级
- **含义**：记录模板所属文档层级：1=手册 2=程序文件 3=作业指导书 4=纯记录表单（可与 2/3 重叠），入编号第 2 段

## Windows 原生部署
- **含义**：不依赖 Docker 的部署形态：Windows 上直接运行 Python(uvicorn)+前端构建产物，由 setup.ps1 一次性部署、start.bat 日常启动

## SPA 回退
- **含义**：单页应用路由回退：访问 /dashboard 等非静态文件路径时由服务端返回 index.html，交给前端路由处理

## 工作台
- **含义**：用户登录后的首屏（role workbench）：按角色呈现当天该做的事——问候、大动作卡（新建客户/报价/委托）、概览数字、最近客户与待办。区别于 ERP 的菜单树首页。

## 示例数据
- **含义**：工作台概览卡上的占位统计值（本月委托/在测样品/待出报告），对应模块上线前标注“示例”标签，非真实数据。

## 已落单
- **含义**：报价状态——客户已接受报价（issued→finalized 迁移）。已落单的报价可一键转委托单，继承客户/项目信息。

## 标准项目
- **含义**：标准（官方号如 GB 9254-2008）下的具体测试项目：类别（EMI/EMS）/方法/判据，1→1 关联记录模板。属标准库（里程碑3）；报价明细当前以项目名称文本引用，标准库上线后挂库引用。

## 确认委托
- **含义**：业务对委托单的确认动作（draft→confirmed），确认后系统自动生成测试任务（任务模块里程碑3 落地，本期为预留钩子）

## 已终止
- **含义**：委托单/样品等的异常终态：任意非终态可由管理直接终止，跳过后续正常流转；需留终止时间与操作人

## 流转留痕
- **含义**：样品/单据每次状态变更写入事件记录（from/to 状态、操作人、时间、备注），形成不可篡改的流转历史；样品页按时间倒序展示

## 标准项目引用
- **含义**：报价明细/测试任务对标准库 standard_items 的外键引用（M3 起）：此前明细以项目名称文本承载，挂引用后任务可继承类别/方法/判据；文本字段保留为兜底

## 打回重测
- **含义**：管理对已完成测试任务的驳回动作（完成→测试中），需留原因；样品与委托单不受影响，任务重新执行
